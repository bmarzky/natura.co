# natura.co
Sebuah landing page premium dan responsif untuk natura.co, toko kue artisan yang menawarkan Classic Black Forest. Dilengkapi dengan sistem ulasan pelanggan waktu-nyata (real-time) menggunakan Supabase, animasi korsel (carousel) otomatis, dan antarmuka dinamis yang berubah mengikuti waktu (morning, day, golden hour, night).
